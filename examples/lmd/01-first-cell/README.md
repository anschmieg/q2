# A first lmd cell

Demonstrates the motivating example: one cell that maps a front-matter list to a markdown fragment per item.

This example backs the lmd page of the Quarto 2 documentation
(`docs/guides/authoring/lmd.qmd`).

## Run it

From the repository root:

```bash
cargo run --bin q2 -- render examples/lmd/01-first-cell
```

The output is `document.html` next to `document.qmd`.
