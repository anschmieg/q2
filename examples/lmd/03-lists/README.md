# Lists from lmd

Demonstrates a tight bullet list from inline fragments, items with several blocks from block fragments, a section per item, and an ordered list.

This example backs the lmd page of the Quarto 2 documentation
(`docs/guides/authoring/lmd.qmd`).

## Run it

From the repository root:

```bash
cargo run --bin q2 -- render examples/lmd/03-lists
```

The output is `document.html` next to `document.qmd`.
